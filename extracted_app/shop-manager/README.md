# إدارة المتجر — النسخة المجزّأة

التطبيق نفسه دون أي تغيير في السلوك، لكن الكود مقسَّم إلى ملفات صغيرة بحسب الوظيفة.

## التشغيل
- للتجربة السريعة: افتح `dist/shop-manager.html` (ملف واحد مدمج).
- لإعادة البناء بعد أي تعديل: `node build.js` (أو `npm run build`).
- أثناء التطوير يمكن فتح `index.html` مباشرة، لكن بعض المتصفحات تمنع تحميل الملفات من القرص، فالأسهل استخدام ملف `dist`.

## البنية
| الملف | محتواه |
|---|---|
| `js/state.js` | المتغيرات العامة وقاعدة البيانات `db` والحفظ والتحميل |
| `js/storage.js` | التخزين: IndexedDB (مع الرجوع إلى localStorage)، والترحيل التلقائي، والنسخ المحلية، والأرشيف |
| `js/utils.js` | دوال مساعدة (تنسيق الأرقام والتواريخ وغيرها) |
| `js/data/` | بيانات ثابتة: الثيمات (`themes.js`) وأنواع المتاجر (`store-types.js`) |
| `js/i18n.js` | الترجمة إلى الإنكليزية |
| `js/ui.js` | النوافذ والنماذج والجداول والقوائم المنسدلة |
| `js/nav.js` | التنقل بين التبويبات وزر الرجوع |
| `js/auth.js` | الرمز السري والبصمة وحساب الموظف |
| `js/notify.js` | التنبيهات والإشعارات |
| `js/backup.js` | نسخ Drive اليومية والاستعادة مع المعاينة، وتصدير الملفات، وأرشفة المتجر |
| `js/scanner.js` | مسح الباركود |
| `js/store-type.js`، `js/theme.js` | نوع المتجر والمظهر |
| `js/receipt-*.js`، `js/receipts.js` | الإيصالات: الرسم والنموذج والمشاركة |
| `js/reports.js` | الرسم البياني والتقرير الشهري والجرد |
| `js/partners.js` | الشركاء وتسوية الأرباح |
| `js/inventory.js`، `js/recurring.js` | الجرد الدوري والمرتجعات والمصاريف المتكررة |
| `js/crud.js` | إضافة وتعديل وحذف السجلات وتسديد الدفعات |
| `js/tabs/*.js` | عرض كل تبويب في ملف مستقل |
| `js/render.js` | الهيكل العام للرسم، ويستدعي ملف التبويب المناسب |
| `js/events.js` | مستمعات النقر والتغيير |
| `js/app.js` | التشغيل الأول (آخر ملف يُحمَّل) |

## قواعد مهمة
1. **ترتيب الملفات في `index.html` مهم:** البيانات والأدوات أولًا، و`app.js` أخيرًا.
2. **لإضافة تبويب جديد:** أنشئ `js/tabs/اسم.js` يبدأ بـ `TAB_VIEWS.مفتاح=function(inR,r){var h='';...;return h};`، وأضفه في `index.html` قبل `render.js`، وأضف اسمه في `TABS` داخل `state.js`.
3. الدوال ما تزال عامة (global) كما في الأصل، والانتقال إلى وحدات ES خطوة لاحقة منفصلة.

## التخزين والنسخ الاحتياطي
- البيانات تُحفظ في **IndexedDB** (سعة أكبر بكثير من localStorage). عند أول تشغيل تُنقل البيانات القديمة تلقائيًا بعد التحقق من تطابقها، وتبقى نسخة localStorage الأصلية دون مساس.
- إن لم يتوفر IndexedDB يعمل التطبيق بالطريقة القديمة (localStorage).
- **لا يُكتب شيء قبل نجاح قراءة البيانات** (حماية من الكتابة فوق بيانات سليمة).
- **نسخ محلية:** نسخة تلقائية يوميًا (آخر 7)، ونسخ يدوية (آخر 10)، ونسخة أمان قبل كل استعادة (آخر 5). تظهر في الإعدادات.
- **Drive:** ملف لكل يوم `shop-backup-YYYY-MM-DD.json` مع حفظ آخر 7، ولا يُرفع شيء إن كانت البيانات فارغة. الاستعادة تعرض معاينة (عدد المنتجات والمبيعات... في النسخة وفي الحالية) قبل التنفيذ.
- الرمز السري والبصمة خاصان بالجهاز ولا يتغيران عند الاستعادة (إلا إن لم يكن على الجهاز رمز).

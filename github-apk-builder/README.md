# 📱 بناء ملف تطبيق أندرويد (APK) مجاناً بواسطة GitHub Actions
# Build Android APK for Free using GitHub Actions

هذا المجلد يحتوي على كامل الملفات الجاهزة لبناء ملف **ShopManager.apk** بصورة آلية وسحابية 100% عبر خوادم GitHub بدون الحاجة لتثبيت أي برامج أو Android Studio على جهازك.

---

## 🚀 خطوات الحصول على ملف APK في دقيقتين:

### الخطوة 1: إنشاء مستودع جديد على GitHub
1. ادخل إلى حسابك في [GitHub](https://github.com) واضغط على **New Repository** (مستودع جديد).
2. اختر اسماً للمستودع مثل `shop-manager-apk`.
3. اضغط **Create repository**.

### الخطوة 2: رفع ملفات هذا المجلد
1. في صفحة المستودع، اضغط على **uploading an existing file** أو قم برفع الملفات عن طريق Git:
   - مجلد `.github/` كاملاً (الذي يحتوي على `workflows/build-apk.yml`)
   - ملف `index.html`
   - ملف `package.json`
   - ملف `capacitor.config.json`
2. اضغط **Commit changes**.

### الخطوة 3: التوليد التلقائي لملف APK
1. بمجرد رفع الملفات، توجه إلى تبويب **Actions** في أعلى صفحة المستودع.
2. ستجد سير العمل بعنوان **Build Android APK** قد بدأ العمل تلقائياً (بعلامة صفراء تدور).
3. انتظر حوالي دقيقة ونصف حتى تظهر علامة الصح الخضراء ✅.

### الخطوة 4: تنزيل ملف APK
1. اضغط على التشغيل المكتمل (Build Android APK).
2. انزل إلى قسم **Artifacts** في أسفل الصفحة.
3. اضغط على **ShopManager-APK** لتحميل الملف مباشرة إلى هاتفك أو جهازك وتثبيته!

---

## ⚡ طرق إضافية لتثبيت التطبيق على أندرويد:
1. **تثبيت PWA فوري بدون ملفات**: افتح رابط التطبيق على هاتف أندرويد بمتصفح Chrome واضغط «إضافة إلى الشاشة الرئيسية» أو «تثبيت التطبيق».
2. **عبر موقع PWABuilder**: ضع رابط الموقع على https://www.pwabuilder.com واضغط Package for Android للحصول على APK فوري.
